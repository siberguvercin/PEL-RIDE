# 🚴‍♂️ Bisiklet Sürüş Takip Platformu

Bisiklet sürüşlerini kaydetmek, harita üzerinde rotaları görüntülemek ve performans verilerini (mesafe, hız, tırmanış vb.) analiz etmek için geliştirilmiş web tabanlı takip uygulaması.

## ✨ Özellikler
- **Rota Görselleştirme:** Sürüş rotalarını interaktif harita üzerinde detaylı inceleme.
- **Sürüş İstatistikleri:** Toplam mesafe, süre, ortalama hız ve yükseklik kazanımı hesaplamaları.
- **Sürüş Geçmişi:** Geçmiş antrenman ve turları listeleme ve karşılaştırma.

## 🚀 Kurulum ve Kullanım
1. Bu depoyu bilgisayarınıza indirin (`Code > Download ZIP`).
2. Klasör içerisindeki ana dosyayı (`index.html`) tarayıcınızda açın.
